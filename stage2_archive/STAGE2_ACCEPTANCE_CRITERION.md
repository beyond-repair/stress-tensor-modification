# Stage-2 Acceptance Criterion (Repository Invariant)

**Mirror of coherence-drive/docs/STAGE2_ACCEPTANCE_CRITERION.md**

A constitutive map is **tested** only after:

1. Continuum formulation is frozen.
2. Spherical control is solved.
3. Joint refinement study is completed.
4. Residual exceeds control floor.
5. No parameter is selected using the thrust target.

Residuals at or below the floor → **null**.  
Steps incomplete → **untested**.  
Target fitting → **invalid study**.

Archived scalar and Proca P-E2 paths: **null** under this criterion.

Claim flags remain false.
